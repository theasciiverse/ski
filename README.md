# Ski!

Evade the deadly Yeti on your jet-powered skis: a silly 1980s terminal
game, one line per turn.

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

```
av install ski
av play ski
```

Type `?` in the game for help.

## Credits

Mark Stevans wrote Ski! between 1983 and 1990; Eric S. Raymond ported it
to Python and maintains it (http://www.catb.org/~esr/ski/). This edition
is that Python version ported to Rust, so it runs without Python on
Linux, macOS and Windows; see PATCHES.md. BSD-2-Clause, see COPYING.
